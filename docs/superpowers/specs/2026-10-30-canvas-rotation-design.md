# Nexora 画布轮换

用户已确认：所有用户共用分配池，每张新画布最多 5 个请求，成功/失败均计数，批量视频算一次；同一幂等请求不重复计数。按北京时间新建日期命名 `Nexora-YYYYMMDD-NNN`，跨天不继续分配昨日画布。旧任务保持原画布。

转正严格计数并固定原画布；满 5 次后拒绝转正，不迁移素材、不提交计费。历史大画布不追溯拆分，已超过上限的旧画布拒绝新增转正。

采用桥接层持久化分配台账及任务 projectId，不修改 New API 协议或插件。固定全局画布不能轮换；仅按内存计数会在重启时超配，因此使用原子文件、进程独占锁及串行分配。台账先落盘、再保存任务；不确定的磁盘故障保守保留名额，重试同一 key/digest 复用。无自动删除台账。

创建画布按官方 `canvas create <name> --project-id=<uuid>`，先持久化 UUID，在任务准备阶段延迟创建；失败只重试同一 UUID，绝不兜底到旧画布。所有上传、提交、轮询和下载显式使用任务画布。启用开关 canvasTaskLimit=5；0 保留固定画布模式，但已绑定任务始终走其原画布。

不改变团队、价格、并发、排队窗口或积分批准。部署只验证空画布创建与读取，不额外提交付费视频。
